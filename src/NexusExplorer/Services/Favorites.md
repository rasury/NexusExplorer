# 收藏行为与边界

- 收藏是左侧树固定置顶的虚拟分类，金色星形标识，不创建物理目录。
- 文件只有一个稳定 ID 和一份位置记录，`IsFavorite` 表示收藏关系；普通分类和收藏列表可以同时展示它。全局搜索不会因此重复显示。
- 从普通分类移除文件，或移除整个普通分类时，已收藏文件保留记录，归属转为保留 ID `-1`。该记录仅用于保持既有外键约束，不参与普通目录、排序、导览目标和整理。
- 在收藏列表执行“取消收藏”不影响原分类和物理文件。若已无普通分类，取消收藏会撤销最后一份登记，但文件仍留在原位置。
- “删除文件”和“删除普通分类”仍遵循物理删除语义：成功后所有视图都不再显示已删除文件；回收失败保留登记与收藏。
- 收藏本身不能重命名、删除、移除、拖动、新建子分类或整理。已登记文件可拖入收藏，仅加星，不改变归属或自动切换播放。外部文件先导入普通分类再收藏。

## 已检查的潜在问题

1. **两份记录路径不一致**：不复制 Files 记录；重命名、整理、分类改名和重新定位沿用同一位置模型。
2. **取消收藏误删原分类登记**：普通归属仅清除标记；仅收藏文件才撤销最后登记。物理文件始终不动。
3. **删除原分类导致收藏丢失**：移除事务先将收藏文件转为保留归属，再删除其余记录；外键和事务保留原失败回滚语义。
4. **星星误触播放或拖拽**：按钮保持独立命令，面板排除 ButtonBase 命中；命令执行中禁用再次点击。
5. **收藏操作把“已整理”变橙色**：数据库触发器只监听归属、名称和位置字段，收藏标记不影响整理状态。
6. **播放中移除原分类导致导航过期**：只刷新实际改变归属的当前文件与导览，不重新播放。
7. **收藏成为普通目录目标**：界面隐藏危险菜单，服务层拒绝目录操作；保留分类不进入普通分类查询。

## 升级与限制

数据库版本4新增收藏标记与索引。沿用备份、副本迁移、成功后写回的机制；保留ID冲突时停止升级，不覆盖旧数据。新库不能交给仅支持版本3的旧程序打开。

应用之外直接改名、移动或删除物理文件，仍会导致失效；收藏不会额外复制文件，也不会自动猜测新路径，可沿用“重新定位”修复。

用户已有同名“收藏”普通分类不会被改名或合并：固定收藏显示金色星星，普通分类仍显示文件夹。由旧数据本身造成的重复文件记录不在本功能中自动合并。

验证使用独立临时库和文件，覆盖共享身份、路径联动、移除后保留、取消收藏、删除失败、固定分类保护、版本3升级、按钮命令绑定及播放导航。真实用户库在首次打开新版时才升级；发布过程不打开或迁移用户库。
