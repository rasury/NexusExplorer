## 检查结果

- Release 构建 0 警告、0 错误，108 个测试通过、0 失败、0 跳过。
- 在独立真实数据副本上，视频目录共 4,189,516,108 字节。首次改名 290.7 ms，改回 27.9 ms；移入分类 38.5 ms、移回 21.6 ms，文件查询 22.0 ms。这是本机服务操作计时，不能代表所有磁盘、外部文件锁或完整 UI 绘制耗时。
- 新包发布到 NexusExplorer-2.0.1-preview-win-x64，不覆盖旧运行目录。其数据副本保留本轮验收新增内容。

SQLite 的 Async API 本身会同步执行，故后台调用是本轮卡顿修复的一部分，参考 [Microsoft 官方说明](https://learn.microsoft.com/en-us/dotnet/standard/data/sqlite/async)。
