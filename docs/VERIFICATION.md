## 音频实测

用户描述为“破音、杂音”。MP3 为 320 kbps、44.1 kHz、双声道、178.756 秒。独立解码前 30 秒的峰值约 0.938，没有超过 0 dBFS 的样本。

实际生产播放器的前 10 秒 PCM，通过 LibVLC 3 支持的 S16N 回调采集，与 FFmpeg 浮点参考按原采样率对齐：偏移 0 样本，相关系数 0.999999986，RMS 误差 0.00000880，信噪比约 75.56 dB，无削波。差异处于 16 位量化范围。诊断回调替代了系统音频输出，不能据此认定设备实际破音已解决；正式应用仍使用默认 mmdevice/WASAPI 输出，没有启用诊断回调。

独立验证工具是项目内下载的 FFmpeg 9.0.2 Gyan Essentials，来源见 [FFmpeg 官方下载页](https://ffmpeg.org/download.html)，下载 SHA-256 已核对。FFmpeg 不随应用分发。VLC 内置 libavformat 能力可查阅 [对应源码](https://github.com/videolan/vlc/blob/3.0.21/modules/demux/avformat/demux.c)。
