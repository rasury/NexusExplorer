# NexusExplorer 2.0 预览版验收

此表是待执行的人工验收步骤，不代表全部问题已经通过。使用独立验收目录与测试文件；旧软件目录保留，真实数据迁移在其副本上进行。完成后反馈编号、结果和日志。

## 准备

1. 保留完整便携目录，双击 NexusExplorer.exe。不要把新程序覆盖进旧软件目录。
2. 建立分类 A、A/子类、B；导入至少 6 个视频、音频、图片混合文件，另准备一个未登记文件。
3. 保留一个“逻辑归属 B、实际位于 A/子类”的文件，用来验证位置与归属独立。
4. 媒体问题复现时记录原文件路径、容器/编码、硬件解码开关、音轨、操作顺序和日志。与官方 VLC 使用同文件、同轨、同音量对比。

## 数据与故障补充

- 删除 A 时，逻辑归属 B 的文件、未登记文件和非空目录仍保留；仅 A 子树所属登记文件进入回收站。
- 在副本上测试旧库升级，确认 before-v2 备份存在，分类 ID、文件 ID、归属、固定状态保持；不识别结构时停止，不创建空库代替。
- 大文件、目标冲突、磁盘空间不足或外部文件锁时确认原件存在、错误明确；整理失败后的成功项仍可打开。
- 整理期间退出会等待当前文件处理一致性完成。中途进程异常后的恢复由操作日志执行；恢复失败时现场保留且后续修改被阻止。
- 跨盘迁移先复制验证、登记目标、再清理源；真实跨盘场景需在可回收的测试文件上验收。
- 图片默认适合窗口，从适合窗口放大、缩小、平移、1:1、前后切换均正常，按钮一直可用。
